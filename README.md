# Schulden-Manager

Installierbare Web-App: https://franktsidie.github.io/schulden-manager-app/

Die Daten bleiben im Browser des jeweiligen Geräts. Regelmäßig unter Einstellungen ein JSON-Backup exportieren. Der App-Passwortschutz verschlüsselt keine lokalen Daten.

GitHub-Backups gehören in ein separates **privates** Repository, niemals in dieses öffentliche App-Repository. Den dafür nötigen Fine-grained Token nur für das private Backup-Repository mit Contents: Read and write ausstellen. Optionales Backup-Verschlüsselungspasswort sicher aufbewahren.

Installation: iPhone/Safari → Teilen → Zum Home-Bildschirm. Android/Chrome → App installieren.
